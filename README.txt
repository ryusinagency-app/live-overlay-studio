Live Overlay Studio v0.66.06

今回の更新
- GTAなどのゲームを前面表示するとショートカットが効かなくなる問題を修正しました。
- Windowsキーフックとキー状態の直接監視を併用する二重監視方式に変更しました。
- 二重監視で同じキーが2回加算されないよう、入力の重複防止を追加しました。
- ガチャ始動演出にON／OFFを追加しました。OFFにしても設定した画像・動画・音源は保持されます。
- 始動演出OFF時は始動素材を飛ばし、通常抽選演出から開始します。
- ガチャ始動・当たり・はずれ演出の画像、動画、音源を解除しても再生される問題を修正しました。
- 素材解除時は保存データ側も即時消去し、古い素材URLが残らないようにしました。
- 結果WIN数の判定値を0にした場合、当たり・はずれ演出を両方OFFにします。
- 継続条件のチェックをすべて外した場合も、当たり・はずれ演出を両方OFFにします。
- WINガチャのURLを「カード内用」と「画面いっぱい用」の2本に分けました。
- URLはパターン番号ごとには変わりません。パターン1・2以降も、表示方法が同じなら同じURLで動きます。
- 各パターンの表示方法に応じて、カード内用または画面いっぱい用の対応するオーバーレイだけで再生します。
- 両方の表示方法を使う場合は、2本ともTikTok LIVE Studioへ登録してください。
- パターン追加後に表示方式とURLが合わず、ガチャが待機列で止まる問題を修正しました。
- 設定パネルを開いている間も、演出中・待機件数が操作画面へ更新されます。
- 停止した待機列を復旧ボタンで再開できるようにしました。
- 既存のプロファイル、ランキング、演出設定はそのまま引き継ぎます。

差し替え方法
1. ZIPを展開します。
2. 中のファイルを現在のアプリフォルダーへ上書きコピーします。
3. アプリを再起動し、操作画面に v0.66.06 が表示されることを確認します。

v0.66.06 の変更
- WINガチャ表示ページの二重HTML宣言を解消し、TikTok LIVE Studio内蔵ブラウザの読み込み互換性を改善。
- 先バレ動画・音源の再生開始が応答しない場合でも、ガチャが待機のまま止まらないようタイムアウトを追加。
- その他ガチャの画像・動画・抽選音源・結果音源が、選択中プロファイルの古い設定に戻って保存できない問題を修正。
- その他ガチャのテスト抽選・連続抽選・終了処理を選択中プロファイルへ同期し、待機中のまま回らない問題を修正。

v0.66.05 の変更
- TikTok LIVE Studio内で通常プレイヤーの初期化が止まった場合、互換プレイヤーが確実にガチャ待機を引き継ぐように修正しました。

v0.66.04 の変更
- WINガチャの結果音源が再生開始できない場合でも、結果画面で停止せず次の演出へ進むように修正しました。

v0.66.03 の変更

- LIVE StudioがループバックURLを読み込めない環境向けに、PCのLAN IPv4アドレスを自動検出します
- 操作画面の全オーバーレイURLをLANアドレス形式で表示します
- サーバーをLANアドレスからも到達できるよう変更しました
- 初回起動時にWindows Defenderの確認が出た場合は「プライベートネットワーク」を許可してください

v0.66.02 の変更

- TikTok LIVE Studioで全オーバーレイURLが読み込み中のままになる問題への対策
- コピー用URLを localhost から従来の 127.0.0.1 形式へ戻しました
- 全リンクのキャッシュ更新番号を統一しました

v0.66.01 の変更

- TikTok LIVE StudioでWINガチャが何も表示されない問題への互換性対策
- LIVE Studioが対応していない可能性がある新しいJavaScript構文をガチャ表示から除去
- 操作画面のコピー用オーバーレイURLを localhost 形式へ変更
- Chromeでの表示、既存のガチャ設定、ショートカット設定はそのまま維持

v0.66.00 の変更
- GTAなどのゲーム中にショートカットが時々反応しなくなる問題への対策を追加しました。
- Windowsのシステムホットキー登録、キーボードフック、直接キー監視の三重監視になりました。
- 短いキー入力も直接監視で拾えるようにしました。
- 操作画面に設定件数、Windows登録件数、登録競合件数を表示します。

設定ファイルは上書きしません。念のため、差し替え前にアプリフォルダーのコピーを保存してください。
