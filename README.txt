Live Overlay Studio v0.66.42

【v0.66.42：パチンコの＋／−／±選択】
・パターンごとに「＋ガチャ」「−ガチャ」「±選択」を設定できます。
・＋／−は終了時に、合計WINを現在WINへ加算／減算します。
・±選択は終了画面で＋か−を選ぶまで待ち、選択時に現在WINへ一度だけ反映。
  選択後に、設定した終了画面の秒数を表示して次の抽選へ進みます。
・操作画面の＋／−ボタンと、パチンコ専用の任意ショートカットを使えます。
  ショートカットは最初は未設定です。結果表示前のキー操作は確定に使いません。
・テストとプレビューの±選択は、実際の現在WIN・履歴に反映しません。
・選択前のスキップはWINを反映しません。すでに選択・確定した結果の表示を
  スキップする場合は、反映済みのWIN・履歴を取り消しません。
・LIVE Studio実機での確認はこれからです。

【v0.66.42：パチンコの突入・終了演出】
・「見た目と演出素材」に、リーチ／CZ／大当たり／ST／上位ST／LTごとの
  「突入」「終了」を並べます。狭い画面では縦に並べます。
・合計12演出それぞれにON/OFF、動画・画像、音源、動画音量、音源音量、秒数を設定。
  初期状態はOFFです。演出中の既存素材は同じグループに残します。
・STから上位STなどへの移行時は、旧モード終了→新モード突入の順に再生。
  同じモードの継続中は、SETごとに突入・終了を繰り返しません。
・CZ成功後にSTへ進む場合にも、CZ突入・終了を通るように修正します。
・各突入・終了をプレビューで選んで確認できます。個別プレビューはOFFでも再生可能。
  演出時間は回転時間・結果表示時間とは別に追加されます。
・LIVE Studio実機での確認はこれからです。

【v0.66.42：継続式の2種類のはずれ】
・ST／上位ST／LTそれぞれに、継続式専用のはずれ設定を追加します。
・「終了する回をはずれ（WINなし）にする」をONにすると、継続判定に落ちた
  回はWINを獲得せず終了します。OFFでも終了判定は残り、従来どおりその回の
  WINを獲得して終了します。
・「WINなしで継続するはずれを使う」はON/OFFと発生率を設定できます。
  発生率は継続判定に通った回の中での割合です。継続率自体は変わりません。
  継続はずれではWINを加算せず、同じモードを続行します。
・表示は「はずれ・継続！／0 WIN」と「はずれ・終了／0 WIN」に分けます。
・初期状態は両方OFFです。回数式には適用しません。
・LIVE Studio実機での確認はこれからです。

【v0.66.41：パチンコ演出の動画・音源の個別音量と連続ループ】
・「見た目と演出素材」の各演出に、動画の音量と音源の音量を分けて設定。
  既存の共通音量は両方へ引き継ぎます。動画だけ0%・音源だけ0%も可能です。
・演出の動画・音源は再生終了時にループします。
  同じ素材を使う回転・リーチ・結果表示では再生プレイヤーを作り直さず、
  再生位置を維持します。STもST用素材を回転・結果表示中まで使用します。
・停止・リーチ素材が未設定なら、それまでの演出を途切れさせず維持します。
  別の素材を設定した演出への切り替え時は、その素材へ切り替わります。
・専用の回転音を使っても、演出用に設定した音源を途中で停止しません。
・プレビュー中も個別音量変更が反映されます。終了・スキップ・停止では音も停止。
・v0.66.41以降で使用できます。実機での動画・音源のループ境目の確認はこれからです。

【v0.66.40：パチンコの先バレ音量・プレビュー・スキップ】
・既存の先バレ音量欄について、旧形式と現行形式の音量保存先を同期します。
  旧形式しか音量がない場合も引き継ぎます。0%は消音として扱います。
・再生中の先バレにも音源・動画音量の変更を反映します。
  追加音源と動画内の音は別の音量です。両方を消す場合は両方0%にします。
・各パターンにプレビューを追加。通常・時短・ST・上位ST・LTの回転、
  リーチ、当たり、突入、終了、各先バレを選択して確認・再生・停止できます。
  プレビューは本番の抽選、待機列、WIN、履歴に追加しません。
・再生中の抽選、待機の1件、表示中の待機すべてを明示操作でスキップできます。
  スキップした抽選はWIN・履歴に反映しません。古い一覧の操作は照合して拒否します。
・再生中のスキップで映像・音・待機処理を中断し、次の抽選に進みます。
  再生状態の確認には履歴や全パターンを含まない小さなデータを使います。
・v0.66.40以降で使用できます。LIVE Studio実機での確認はこれからです。

【v0.66.39：パチンコガチャ設定の追加・時間設定の修正】
・通常抽選／時短／ST／上位ST／LTに、当選WIN数と確率の候補表を追加。
  従来の固定WIN・最小〜最大と切り替えられます。候補表は切り替えても保持します。
  確率0%の候補は抽選しません。合計100%以外は相対比率として扱います。
  候補なし・全候補0%では従来のWIN設定を使用します。
・ST／上位ST／LTで「回数式」と「継続式（WIN抽選→継続率判定）」を選択可能。
  既存のST／上位STは回数式、既存のLTは継続式を維持します。
・数字ごとに使用ON/OFFを追加。回転中・リーチ・停止結果すべてに反映。
  はずれがゾロ目にならないよう、使用する数字は最低2種類必要です。
・通常抽選の回転時間と結果表示時間が同じ項目を上書きしていた不具合を修正。
  各モードの回転時間、結果WINの表示時間、突入演出の表示時間を個別に設定できます。
  リーチ時間・数字停止音の時間・終了画面の時間は、それぞれの設定で追加されます。
・初当たり画面に最終合計WINが表示されていた箇所を、初当たり分のWINに修正。
・操作画面のパチンコURLにも実行バージョンの更新番号を付けます。
・v0.66.39以降で使用できます。

【v0.66.38：WIN表示の軽量化と診断表示】
・現在WINは数字・見た目の設定に変更があるときだけ描画を更新します。
・WINガチャの共通文字設定は、変更があるときだけ画面へ適用します。
・WINガチャ／現在WINの表示URLの末尾に &lite=1 を付けると軽量表示にできます。
  「?」のないURLの場合は ?lite=1 を付けてください。
・軽量表示では標準の背景回転・揺れ・明滅・影などを省略します。
  動画そのもの、音声、結果画像、抽選時間、±選択の進行は通常と同じです。
・軽量表示と診断表示はv0.66.38以降で使用できます。
・WINガチャURLに &diagnostic=1 を付けると、画面上に時計・通信成功回数・
  抽選ID・動画の再生位置・直近のエラーを表示できます。
  配信に映るため、配信前の確認用です。確認後は diagnostic=1 を外してください。
・LIVE Studioでの停止やゲームFPS低下の解消を保証するものではありません。

v0.66.37 現在WIN・WINガチャの通信負荷改善
表示専用の小さい応答を追加し、履歴・別プロファイル・別パターンの不要なデータを送り続けないようにしました。現在WINの数字・見た目・音を1つの通信で更新し、遅い通信が何重にも重ならないようにします。書き込み時は表示用キャッシュを更新し、短時間の同時読み込みを共有します。PCの操作画面でコピーするURLは127.0.0.1を使用し、スマホなどから開いた操作画面ではLAN用URLを維持します。現在WINにもバージョン付きリンクを適用。更新後は操作画面をCtrl+F5で再読み込みし、現在WINとWINガチャ両方のリンクをLIVE Studioへ貼り直してください。実際のLIVE Studioで停止が解消するかは未確認です。
