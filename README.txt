Live Overlay Studio v0.66.23

今回の更新
- パチンコガチャの表示表記を「AT／上位AT」から「ST／上位ST」に変更しました。抽選処理や保存データの内部キーは変更していません。
- ST／上位STの継続率設定を、各モードの回転数とモード中の当選確率（分子／分母）へ変更しました。設定回転数内に当選するとWINを獲得して継続し、当選しなければ終了します。
- 時短・ST・上位ST・LTそれぞれに、1回転あたりの表示秒数を追加しました。
- リーチ演出をパターンごとにON／OFFできるようにしました。

今回の更新
- WINガチャとパチンコガチャの表示文字を、役割ごとにON／OFF、任意テキスト、個別文字色、文字サイズへ変更できるようにしました。
- START、抽選中、結果WIN、今回WIN、SET、最終合計などを、任意の画像へ置き換えられるようにしました。
- 任意テキストでは {text}、{value}、{name}、{set} の差し込みに対応しています。
- 現在WINの「増加・減少・目標到達」効果音に、それぞれ独立した音量設定を追加しました。
- WINガチャの「抽選数字・効果音・上位ATの詳細設定」が、素材を設定・解除しても閉じないようにしました。
- WINガチャ始動時の標準「ポン」音をON／OFFでき、任意音源への差し替え・音量調整・試聴・解除にも対応しました。
- パチンコガチャの各設定欄が、画像・動画・音源を設定・解除しても開いた状態を保持するようにしました。
- パチンコガチャのテスト再生だけを約5倍速にし、設定確認を短時間で行えるようにしました。通常のギフト抽選速度は変わりません。
- パチンコガチャにも最大3種類の先バレを追加しました。大当たり・はずれ・CZ・AT・上位AT・LT条件、各発生確率、回転開始前／回転中／結果直前のタイミングを選べます。
- 先バレごとに画像・動画・音源・テキスト・色・文字サイズ・再生時間・音量を個別に設定できます。音のみ／音＋テキストでも回転中の演出を維持します。
- 回転中の表示数字0〜9をそれぞれ任意文字、フォント、色、サイズ、画像、画像サイズへ変更できます。
- ギフト履歴にページ、連続、1件ずつ、フェード、スライド、固定表示を追加しました。
- WINガチャの抽選中数字を、当選候補のみ／任意数字リストから選べるようにしました。
- 固定WINごとに抽選中画像と結果画像を割り当てられるようにしました。
- 上位ATに専用の抽選時間、WIN範囲、固定数字＋確率、数字画像を追加しました。
- 標準ビープ音と、結果音源未設定時の標準結果音を個別にON／OFFできます。
- 抽選中の2本目音源を追加し、BGMと声・効果音を同時再生できます。
- 専用タブ／専用URLのパチンコガチャを追加しました。ギフト回転、当たり確率、CZ、時短、AT、上位AT、ラッキートリガー、各シーン素材・音源を設定できます。
- パチンコガチャは複数パターン、複製、停止、再開、削除確認、待機列、テスト抽選に対応します。
- WINガチャとパチンコガチャの表示設定を「表示テキスト・画像・位置（統合設定）」へまとめました。
- 「？？？」など表示場面ごとに、表示ON/OFF、任意テキスト、個別文字色、サイズ、フォント、画像、横位置、縦位置を設定できます。
- 個別位置をOFFにした項目は従来の配置を維持するため、既存設定をそのまま引き継げます。
- GTAなどのゲームを前面表示するとショートカットが効かなくなる問題を修正しました。
- Windowsキーフックとキー状態の直接監視を併用する二重監視方式に変更しました。
- 二重監視で同じキーが2回加算されないよう、入力の重複防止を追加しました。
- ガチャ始動演出にON／OFFを追加しました。OFFにしても設定した画像・動画・音源は保持されます。
- 始動演出OFF時は始動素材を飛ばし、通常抽選演出から開始します。
- ガチャ始動・当たり・はずれ演出の画像、動画、音源を解除しても再生される問題を修正しました。
- 素材解除時は保存データ側も即時消去し、古い素材URLが残らないようにしました。
- 結果WIN数の判定値を0にした場合、当たり・はずれ演出を両方OFFにします。
- 継続条件のチェックをすべて外した場合も、当たり・はずれ演出を両方OFFにします。
- WINガチャのURLを「カード内用」と「画面いっぱい用」の2本に分けました。
- URLはパターン番号ごとには変わりません。パターン1・2以降も、表示方法が同じなら同じURLで動きます。
- 各パターンの表示方法に応じて、カード内用または画面いっぱい用の対応するオーバーレイだけで再生します。
- 両方の表示方法を使う場合は、2本ともTikTok LIVE Studioへ登録してください。
- パターン追加後に表示方式とURLが合わず、ガチャが待機列で止まる問題を修正しました。
- 設定パネルを開いている間も、演出中・待機件数が操作画面へ更新されます。
- 停止した待機列を復旧ボタンで再開できるようにしました。
- 既存のプロファイル、ランキング、演出設定はそのまま引き継ぎます。

差し替え方法
1. ZIPを展開します。
2. 中のファイルを現在のアプリフォルダーへ上書きコピーします。
3. アプリを再起動し、操作画面に v0.66.23 が表示されることを確認します。
4. TikTok LIVE StudioのパチンコガチャURLを、操作画面からコピーした build=6623 の新URLへ貼り替えます。
