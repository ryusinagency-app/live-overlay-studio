起動方法（Windows）
1. ZIPを展開
2. Python 3 をインストール（未導入の場合）
3. start.bat をダブルクリック（数秒後に操作ページが自動で開きます）
4. 操作ページの「オーバーレイリンク」から、表示したい項目のURLをコピーします。禁煙タイマー、禁煙ガチャ、ギフトメディアは専用リンクで追加できます。
5. TikTok LIVE Studioで「ソースを追加」→「リンク」を選び、URLを貼り付けます。ミッション、カウンター、メモ、ギフトタイマーは別々のソースとして追加・配置できます。
6. ギフト連携を使う場合は、操作画面でTikTokユーザー名とギフト名・秒数を設定し、「ギフト受信を開始」を押してください。

配信終了時
黒いコマンド画面を閉じるとサーバーが終了します。設定は同じフォルダーの state.json に保存され、再起動後も読み込まれます。
操作ページは配信画面に出さず、LIVE Studioには操作ページに表示される各オーバーレイ用URLだけを追加してください。
ショートカットが他のソフトと重なる場合は、ゲーム側の割当を変更するか、ショートカットを使わず操作ページのボタンを利用してください。

・各カードの背景色、ライン色、文字色、透過度は、そのカードで選んだ値を直接保存します。一括設定を押さない限り、ほかのカードには反映されません。
・カウンター、ミッション、ギフトタイマー、メモ、禁煙タイマー、現在WIN、ギフト履歴、ガチャ履歴は、それぞれの設定欄から文字サイズを調整できます。WINガチャ演出内の各文字もパターンごとにサイズを設定できます。
・文字の袋文字（縁取り）のON／OFF・色・太さと、文字背景のON／OFF・色・透過度を、全カード共通またはカードごとに個別設定できます。
・個別設定できる対象は、各カウンター、各ミッション、各メモ、各ギフトタイマー、現在WIN、禁煙タイマー、各ガチャパターン、ギフト履歴、ガチャ履歴です。
・現在WINカードの個別色設定を反映する処理を修正済みです。
・ガチャパターンの「＋／－両方・＋だけ・－だけ」と抽選方式の選択中は、自動更新を一時停止するため、選択欄が勝手に閉じません。

ギフト履歴オーバーレイ
・設定したコイン数以上のギフトを受信すると、贈り主名・ギフト名・ギフト画像・個数・合計コイン数を履歴に保存します。連続ギフトは単価×個数で判定します。しきい値未満のギフトは記録枠を使わないため、後から届いた少額ギフトで対象履歴が押し出されません。操作画面にも最大200件を表示し、アバター・ギフト画像・名前・ギフト名を確認できます。オーバーレイ表示のリセットは保存履歴を残します。
・専用リンクから単独配置できます。列数・行数・ページ切替秒数と縦／横の切替方向を設定できます。履歴は最大200件です。

WINガチャ
・現在WINカウンターとWINガチャは操作画面・オーバーレイとも別々です。現在WINはマイナス表示にも対応します。
・現在WINだけを変更するショートカットを割り当てられます。WIN増減ギフトも個別に登録できます。
・WINガチャは発動ギフトとパターンごとにWIN範囲または複数の固定値と確率、＋だけ／－だけ／＋－両方、一発抽選／継続抽選、継続率を個別設定できます。通常AT継続時に抽選する上位AT突入率と、上位AT専用の継続率・演出動画／画像・音源もパターンごとに設定でき、上位ATを使わない設定にもできます。全画面演出の動画／GIF、数字の位置・サイズ・色、回転時間、止まり方をプレビューしながら調整できます。
・ギフトで抽選した場合、演出カードに送信者の表示名を表示します。テスト抽選では「テスト」と表示します。
・「＋／－両方」は数字だけを抽選し、終了画面で＋か－を選んで確定します。操作画面のボタンまたは変更可能なショートカットを使えます。
・＋か－を選ぶまでは終了画面が消えず、現在WINにも反映されません。＋だけ／－だけも各ラウンドの結果表示時に反映されます。
・ギフトで抽選を開始し、各ラウンドでスロット抽選中に演出素材を再生、結果を表示してから次ラウンドへ進みます。終了後は任意の画像／動画、表示秒数、終了音源を設定できます。
・ガチャ画面の合計WINは、現在の所持WINではなく今回の抽選で増減した合計です。
・WIN増減ギフトを複数登録でき、増加は正数、減少は負数で設定します。
・WIN増減ギフトは現在WINだけを変更し、抽選イベントやガチャ演出は開始しません。同じギフト名がガチャ発動にも設定されている場合も、WIN増減を優先します。
・現在WINはショートカット（初期Ctrl+Alt+7 / Ctrl+Alt+Shift+7）とWIN表示用オーバーレイに反映されます。
・GIF／MP4／WebM／PNG／JPG／WebP素材を読み込み、各パターンのテストボタンで手動抽選できます。
・抽選中は数字が回転して徐々に止まるスロット風演出と効果音が再生されます。演出時間は3〜30秒、標準効果音の音量は0〜100%で調整できます。
・抽選中と結果表示時の音源（15MB以下）を登録して、それぞれ音量を調整・試聴できます。
・操作画面の「演出プレビュー」では本番のWIN数や履歴を変えず、全画面の動画／画像、ランダム数字、抽選結果を確認できます。
・オリジナル演出に動画を使う場合、動画音声のオン／オフと音量を設定できます。動画・画像の表示を大きくし、画面から見出し文字「WIN CHALLENGE」を外しました。
・WINガチャの演出レイアウト・時間・数字の見た目・抽選素材・抽選中／結果／終了音源・カード色と透過度は、すべてパターンごとに個別設定できます。共通の演出設定はありません。パターンの「複製」で抽選内容と演出設定をコピーできます。発動ギフトは重複発動を避けるためコピー先では空欄になり、必要なギフトを選んで設定します。
・演出素材や音源を選択・解除しても、開いていたパターン設定欄は閉じません。
・上位ATは「通常抽選 → 上位AT当選 → 上位AT突入専用演出（未設定なら省略）→ 上位AT専用抽選演出」の順で再生できます。突入演出と上位AT抽選演出は、画像／動画・音源・音量を別々に設定できます。
・通常ATと上位ATそれぞれに継続専用演出を設定できます。「抽選 → 継続 → 継続演出 → 次の抽選」の順で、ON／OFF、画像／動画、音源、表示時間、音量をパターンごとに保存します。
・ガチャ演出は「カード内固定」「画面いっぱい固定」の2つの専用URLで個別配置できます。
・パターン名、ギフター名、抽選数字・結果、状態表示、START・合計、±選択案内はパターンごとに表示ON／OFFできます。±選択案内は文字色と文字サイズも個別設定できます。
・抽選中メッセージの文字色・サイズ・フォントもパターンごとに設定でき、ネオン発光はオン／オフ・色・強さを調整できます。抽選中メッセージや結果の文字色・サイズもパターンごとに設定できます。フォント候補は標準、游ゴシック、メイリオ、太字ゴシック、明朝体、等幅です。
・ガチャ演出、現在WIN、ガチャ履歴は個別URLで配置できます。履歴には最近の抽選者名・パターン名・今回の獲得WINを操作画面とオーバーレイに最大8件表示し、内部には最大20件保存します。抽選が最後まで終了したときに記録されます。
・操作画面右上にTikTokギフト接続パネルが常時表示されます。接続状態を確認し、受信ON／OFFをどの設定画面からでも切り替えられます。OFF中はすべてのギフト反応を停止します。
・ギフトタイマー、現在WINの増減ギフト、WINガチャの発動ギフトは「ギフトを選択」を押すと、画像・名前・コイン数つきの一覧から選べます。選択画面は設定時だけ表示され、検索・使用中表示・使用中ギフトの非表示に対応します。
・ギフト一覧はTikTok LIVE接続時に取得します。一覧が取得できない場合も、これまで通りギフト名を直接入力できます。

【その他ガチャ（v0.65.29）】
WINガチャとは独立した抽選を作れます。パターンごとに追加・削除・有効／停止、対象ギフト、一発／継続方式、継続率、複数の結果と相対確率を設定できます。各パターンに画像・GIF・動画、抽選中音源、結果音源を登録でき、その他ガチャ専用オーバーレイへ表示します。結果はWIN数に加算されません。「プレビュー再生」から登録した演出を確認できます。

【プレビューの直接編集】
その他ガチャとWINガチャのパターン設定からプレビューを開き、パターン名・ギフター名・結果・状態などをドラッグして配置できます。WINガチャの文字位置はパターンごとに保存します。未編集の既存パターンは従来の表示を維持します。


【ギフトメディア（v0.65.32）】
操作画面の「ギフトメディア」タブで、対象ギフトに反応する演出パターンを複数作成できます。各パターンに名前・対象ギフト・画像・動画・音源を登録し、表示幅・高さ、動画と音源の音量、再生時間を個別設定できます。パターンは有効／停止を切替でき、削除もできます。複数のギフトが続けて届いた場合は順番に再生します。テストボタンで配信前に確認できます。TikTok LIVE Studioには「オーバーレイリンク」内の「ギフトメディア」URLを別ソースとして追加してください。

【WINガチャの先バレ演出（v0.65.30）】
パターンごとに先バレを有効にし、継続当選・上位AT当選・指定WIN数以上のいずれかを条件にできます。発生タイミングは「抽選開始時」または「結果表示の直前」、テキスト・文字色・表示時間・音量を選べます。先バレ専用の画像・GIF・動画も登録でき、動画音量も個別に設定できます。素材は先バレ中だけ抽選演出の上に表示され、終了後は通常演出に戻ります。プレビューでも条件に合う先バレを確認できます。抽選結果を先に判定してから通知するため、先バレと結果の食い違いを防ぎます。
