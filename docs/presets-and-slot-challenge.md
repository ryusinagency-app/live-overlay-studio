# プリセットと1G連チャレンジ

## プリセット

操作画面の「プリセット」タブで一覧を追加し、「カードを追加」で内容を登録します。各カードにはギフト一覧から選んだギフト画像、任意の画像、説明文を並べられます。矢印で順序を変え、チェックでカード単位の表示を切り替えられます。

デザインはシンプル・ネオン・暖色グラデーションの3種類。列数、カード寸法、間隔、画像・文字サイズ、背景透過、色、フォント、袋文字を変更できます。「カスタムCSS」は専用のプレビューと一覧だけに適用し、リセットできます。使用するクラスは `.presetBoard`、`.presetCard`、`.presetImages`、`.presetDescription` です。

一覧ごとの「URLをコピー」でLIVE Studioへ追加します。URLはこのPCのLANアドレスから生成します。既存のオーバーレイURLを変える必要はありません。

表示用ページは5秒ごとに専用データの変更だけを確認し、変更なしなら内容を再送・再描画しません。動画や自動アニメーションは組み込みません。アップロード画像は静止画として最大512pxに縮小し、GIFも静止画になります。カスタムCSSにアニメーションや重いフィルターを加えると、その分の描画負荷は増えます。

## 1G連チャレンジ

スロットのノーマルタイプで「1G連チャレンジを使う」をONにします。初期値はOFFです。チャレンジ名、回転数、大当たり確率、回転時間、停止間隔、結果表示時間を設定できます。

通常の大当たり後にチャレンジが始まり、規定回転内に当たれば設定回転数から再挑戦します。チャレンジの残り回転と新しい回転枠は重複加算しません。規定回転で当たらなければ通常に戻ります。ギフトで獲得した未消化の通常回転はその後に続きます。大当たりWINと±選択は既存の設定を使います。

突入、チャレンジ中、チャレンジ中の大当たりに画像／動画と音源を個別設定できます。動画と音源の音量・ループ、画像／動画／音源それぞれの時間も変更できます。0秒なら演出や状態の長さに合わせます。専用の大当たり素材を設定していない場合は従来の大当たり素材を使用します。

ATタイプはこの機能の対象外です。ON/OFFと設定変更は、次に開始する抽選から反映されます。進行中の抽選を終えてから更新してください。

## 検証範囲

抽選ロジック、符号付きWINと重複反映防止、複数台の進行、既存AT/CZ、設定保存、専用HTTP API、条件付き応答、DOMでの編集操作、実再生関数での素材・音量・期限・後片付けを自動テストしています。Windows LIVE Studioでの実配信・映像の滑らかさは実機確認が必要です。
