# Live Overlay Studio

最新バージョン: **v0.66.81**

TikTok LIVE Studio向けの配信用オーバーレイ管理アプリです。

## ダウンロードと更新

[最新のWindows版をダウンロード](https://github.com/ryusinagency-app/live-overlay-studio/releases/latest)

Windows版はPythonをインストールせずに起動できます。アプリ起動後に更新を確認し、更新版がある場合は「更新して再起動」から適用できます。設定・履歴はWindowsユーザーごとに保存されます。

ソースZIPから起動する場合はPython 3が必要です。配信者はReleaseのEXEをご利用ください。
